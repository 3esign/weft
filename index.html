Printing WEFT on the A2L, safely

You will not damage the machine with these files, because you preview before you print. Two routes, and running both cross-checks your work:

Route A — STL (trust first). Set bead width to your calibrated single-line width for the mounted nozzle, download the STL, open it in Bambu Studio normally. Arachne recovers each layer as one continuous bead. Studio owns all machine-specific startup — nothing to worry about. Print this first to confirm the geometry and the machine.

Route B — G-code (weld control). This is the same paths plus flow-boost and dwell at every node — the actual method. To keep startup machine-correct:

  1. In Bambu Studio, slice any small object for your A2L and export its G-code.
  2. Open it, copy everything before the first extruding move (the whole start block) into WEFT's header field; copy the end block into the footer.
  3. Download WEFT's G-code, then drag the .gcode file onto Bambu Studio's Preview tab (it opens preview-only; there is no File→Import menu entry for G-code) and look at the preview. Every move renders. If anything shoots off the plate you'll see it instantly.
  4. Only then send to print. Watch the first layer.

If the G-code preview matches the STL slice, your emitter is sound. That agreement is the safety net.
