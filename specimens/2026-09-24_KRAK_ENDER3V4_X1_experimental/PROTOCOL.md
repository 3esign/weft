# KRAK — protocol

1. Print `KRAK_ENDER3V4_X1.gcode` on the Creality Ender-3 V4. Change nothing: no fan, speed or temperature
   edits. The whole object is a comparison and every rung must see the same process.
2. Watch the first ten minutes for adhesion, then the start of K1.
3. Photograph each terrace from a fixed side with a scale, and photograph the object from
   directly above so all ten sectors are in one frame.
4. For each terrace record, per sector: does the comb read as a comb; is the outer edge
   level, drooping or tangled; does it match its twin 180 degrees away.
5. Write the answers into `outcomes.md` in this folder. A rung that disagrees with its
   twin is a machine effect and must be written down as one.
6. Sector 0 on the physical object: on K3 it is the **shortest** fringe.
